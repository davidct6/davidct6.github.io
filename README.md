# David's personal website

A responsive personal engineering portfolio for **davidct6**, focused on RF, FPGA, and high-frequency hardware.

## Files

- `index.html`: page content and accessible markup
- `styles.css`: responsive design
- `script.js`: mobile menu and interactive signal explorer
- `favicon.svg`: browser icon
- `.nojekyll`: tells GitHub Pages to serve these static files directly

No framework, dependencies, tracking scripts, or build step. Open `index.html` in a modern browser to preview.

## Publish on GitHub Pages

1. Use a public repository named `davidct6.github.io`.
2. Add these files at the root of the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/ (root)**, then **Save**.
6. Wait for the Pages deployment to finish. The site will be at **https://davidct6.github.io/**.
7. Confirm **Enforce HTTPS** is enabled.

Updates pushed to the publishing branch are deployed automatically. A custom domain can be connected later.

## Personalize

The notebook entries are explicitly labeled as planned topics, not completed work. Replace them with genuine project descriptions, methods, measurements, and links when ready.

Edit the introduction and about section in `index.html` as your experience develops. Contact links currently point only to your GitHub profile; add a public professional email or LinkedIn link when you choose to share one. No private repository content or account email has been published.

The signal explorer is an illustrative normalized sine wave, not a physical measurement or engineering calculator. Animation starts only when requested and stops when the tab is hidden. Reduced-motion preferences are respected for page transitions.
